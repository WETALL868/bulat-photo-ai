`hiblack-stock-alert-check.php`. Хеши каждого файла и исходного ZIP находятся

Выгрузка **не содержит** `seo-pages/` (сгенерированные HTML-страницы),

`seo-pages/` могут быть пересозданы исходными инструментами, но перед сборкой
надо сверить их с текущим каталогом и SEO-адресами. Команда `npm run build`
заново собирает и каталог, поэтому её не стоит запускать без проверки
источника данных поставщика.
