# Hi-Black — фирменный интернет-магазин

Дизайн-прототип магазина расходных материалов Hi-Black (картриджи, тонеры, чернила, ЗИП).
Статический сайт без сборки: одна HTML-оболочка, стили, данные каталога и небольшой роутер на JavaScript.
Страницы переключаются по `#hash`, корзина, избранное и сравнение хранятся в `localStorage`.

Прототип перенесён из чата и продолжает дорабатываться здесь. Финальная цель — тема для Shop-Script (Webasyst)
и боевой каталог из API поставщика (ВТТ); вёрстка и CSS этого прототипа станут основой темы.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер (так корректно грузятся шрифты):

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000/.

Собрать всё в один файл (стили, скрипты, шрифты и картинки внутри) — чтобы отправить прототип
одним вложением или опубликовать превью:

```bash
node tools/build-single.js            # dist/hi-black.html
node tools/build-single.js --artifact # dist/hi-black-artifact.html — формат для артефакта Claude
```

## Структура

```
index.html                  оболочка: шапка, меню, подвал, мобильное меню, оверлеи
assets/css/styles.css       все стили; разделы пронумерованы, адаптив в конце (≤1240, ≤980, ≤640, ≤380)
assets/css/fonts.css        @font-face для Manrope и Golos Text (локальные копии, OFL)
assets/fonts/               woff2-подмножества шрифтов (кириллица + латиница)
assets/js/data.js           данные каталога: категории, бренды, 90 товаров, тексты страниц
assets/js/icons.js          SVG-иконки (пути внутри <svg>)
assets/js/app.js            роутер, рендер страниц, корзина, фильтры, слайдер, мобильное меню
assets/img/products/        фото товаров (jpg), assets/img/brands/ — логотипы брендов (svg)
assets/img/photo/           фоны слайдера и подвала
tools/build-single.js       сборка в один HTML-файл
```

Маршруты: `#home`, `#catalog?cat=laser&brand=kyocera`, `#product?id=hb-tk-1150`, `#cart`, `#checkout`,
`#order`, `#favorites`, `#compare`, `#finder`, `#login`, `#page?id=delivery` (и другие id из `data.js → pages`).

## Что сделано в этой итерации

Перенос из артефакта: картинки вынесены из base64 в файлы, данные, иконки, логика и стили — в отдельные файлы,
демо-панель переключения страниц убрана (навигация — через сам сайт), шрифты подключены локально.

Мобильная версия:

- убран горизонтальный overflow на главной (карточки и заголовки обрезались справа);
- шапка: бургер, логотип, кнопка звонка и корзина в одной строке, поиск под ними, разделы каталога — прокручиваемые чипы;
- выдвижное меню с каталогом, разделами для покупателей, избранным, сравнением и контактами;
- плитки категорий на телефоне — горизонтальные (текст слева, фото справа), без наезда картинки на заголовок;
- карточки товара в две колонки с компактным рейтингом «4,8 (12)», ценой и кнопкой;
- каталог: тулбар в одну строку («Фильтры» + сортировка), панель фильтров на весь экран с липкой кнопкой
  «Показать N товаров», панель не закрывается при каждом клике по чекбоксу;
- карточка товара: липкая панель «цена + В корзину» внизу экрана после прокрутки блока покупки;
- корзина: исправлена сетка позиций (название больше не сжато в узкую колонку), сводка заказа сразу после списка;
- шаги оформления, сегменты «физлицо/юрлицо», подвал в две колонки, тосты и лайтбокс под маленький экран.

Десктоп: меню разделов больше не обрезается, мега-меню каталога с фиксированной высотой, hover-эффекты
только для устройств с мышью, единые размеры кликабельных зон.

## Заглушки

Телефон, адрес склада, email и реквизиты — заглушки в квадратных скобках, подставляются при запуске.
Фото на слайдере и в подвале — Wikimedia Commons (авторы указаны в подвале), для боевого сайта заменяются на свои.
Отзывы, остатки и цены — примерные данные для демонстрации.
