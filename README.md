# Hi-Black — фирменный интернет-магазин

Статичная витрина расходных материалов Hi-Black: картриджи, тонеры, чернила, ЗИП.
Каталог лежит готовыми JSON-файлами, цены и остатки — отдельным файлом, каждая публичная
страница заранее собрана в HTML. Сервер нужен только для приёма заказов.

Архитектура повторяет решение магазина NV Print, разобранное перед началом работы:
статика вместо движка, живые цены поверх статичного каталога, предрендер ради поиска.
Она заметно дешевле в хостинге и быстрее готового движка, но админку и приём заказов
пишем сами.

## Как это устроено

| Слой | Где лежит | Когда меняется |
|---|---|---|
| Витрина | `index.html`, `assets/` | при доработке сайта |
| Каталог | `data/catalog/` | при полной пересборке, обычно ночью |
| Цены и остатки | `live/catalog-live.json` | по расписанию, хоть раз в час |
| Готовые страницы | `seo-pages/` | вместе с каталогом |
| Приём заказов | `api/index.php` | почти никогда |

Разделение каталога и цен — главное решение. Переоценка не трогает каталог, поэтому
браузер не перекачивает его заново, а страницы не нужно пересобирать ради новой цены.

**Компактный индекс.** В `data/catalog/index.json` товар записан массивом значений без
имён полей, имена лежат один раз в `meta.fields`. Девяносто товаров занимают 22 КБ,
вся первая порция данных — 32 КБ. Подробности карточки (описание, характеристики,
совместимость) лежат в чанках по 32 товара и грузятся только при открытии карточки.

**Настоящие адреса.** Страницы отвечают по путям `/catalog/laser/kyocera`,
`/product/hb-tk-1150`, `/printer/kyocera-m2135dn`, а не по решётке. Каждый такой путь
заранее собран в статический HTML, сервер отдаёт его сразу, и скрипт перерисовывает
страницу поверх уже показанного. Карточка товара читается с выключенным JavaScript:
заголовок, цена, характеристики и описание в ней уже есть.

**Страницы под модели принтеров.** Из совместимости товаров собираются отдельные
страницы вида «Расходные материалы для Kyocera M2135dn». На 90 товарах их 235,
на боевом каталоге будет несколько тысяч — это основной источник поискового трафика.

**Ключи только на сервере.** Витрина ходит в свой `api/index.php`, а он уже наружу.
Настройки и секреты лежат выше публичной папки, путь к ним — в `api/config-path.php`.
Цену заказа сервер берёт из своего файла цен, а не из запроса браузера.

## Запуск

```bash
npm install                    # playwright нужен для предрендера и оптимизации картинок
npm start                      # http://127.0.0.1:8080 с правилами боевого .htaccess
```

Пересборка после изменения каталога:

```bash
npm run catalog                # выгрузка → data/catalog/ и live/
npm run seo                    # готовые страницы + sitemap.xml и robots.txt
npm run build                  # то и другое подряд
```

Прочее:

```bash
node tools/optimize-images.mjs --write --drop   # перекодировать картинки в WebP
node tools/make-art.mjs                        # перерисовать иллюстрации
npm run single                                   # весь сайт одним файлом в dist/
```

## Структура

```
index.html                оболочка витрины: шапка, меню, подвал
assets/css/styles.css     все стили, адаптив в конце (≤1240, ≤980, ≤640, ≤380)
assets/css/fonts.css      Manrope и Golos Text, локальные копии
assets/js/catalog.js      слой данных: индекс, чанки, живые цены, поиск
assets/js/app.js          маршруты, отрисовка страниц, корзина, фильтры
assets/img/               фото товаров и логотипы брендов, WebP
catalog-source/data.js    исходный каталог прототипа (в браузер не попадает)
data/catalog/             собранный каталог
live/                     цены, остатки и отметка о последнем обновлении
seo-pages/                готовые страницы, 375 файлов
api/index.php             приём заказов
tools/                    сборщики: каталог, предрендер, картинки, dev-сервер
.htaccess, _redirects     правила для Apache и для Netlify или Cloudflare Pages
```

## Подключение боевого каталога

Экспортёр `vtt_export.py` (из отдельной работы по API поставщика) собирает
`hiblack_catalog.csv` на 3 421 позицию. Дальше:

```bash
node tools/build-catalog.mjs --source vtt-csv --in out/hiblack_catalog.csv
npm run seo
```

Соответствие колонок CSV описано таблицей `COLUMNS` в начале `tools/build-catalog.mjs`
и правится без изменения остального кода. Обновление остатков в течение дня —
это перезапись только `live/catalog-live.json`, без пересборки каталога и страниц.

## Что ещё предстоит

- Админка: правка цен, наценки и текстов без пересборки вручную.
- Оплата и передача заказа поставщику — каркас в `api/index.php`.
- Личный кабинет с историей заказов.
- Замена заглушек: телефон, адрес склада, email и реквизиты стоят в квадратных скобках.

Иллюстрации слайдера, подвала и меню каталога рисует `tools/make-art.mjs` —
принтеры, МФУ и картриджи в аксонометрии, фирменный чёрный с жёлтым. Права на
рисунки у магазина, подпись под ними не нужна. Раньше там стояли снимки с
Wikimedia Commons: их лицензии разрешают коммерческое использование, но требуют
указывать автора, а CC BY-SA ещё и обязывает открывать переделки под той же
лицензией — для фирменного магазина это лишняя зависимость.

Цветные варианты флаконов чернил в демо-каталоге получены перекраской
(`tools/recolor-ink.mjs`): в выгрузке лежит один цвет линейки, а блок «весь
комплект» показать не на чем. На мелком шрифте этикетки остаётся исходное
название цвета — с приходом настоящей выгрузки Hi-Black эти файлы заменятся
фотографиями поставщика, а тул можно удалить.

Отзывы и оценки в карточках — примеры для демонстрации блока.
