# Файлы, которые лежат выше публичной папки

Публичная папка сайта — корень репозитория: то, что попадает в
`/var/www/ada-russia/data/www/hiblack-msk.ru`. Файлы из `server/` туда
класть нельзя: их запускает планировщик, а не посетитель.

| Файл | Рабочее место на хостинге | Как запускается |
| --- | --- | --- |
| `hiblack-stock-alert-check.php` | `/var/www/ada-russia/data/hiblack-stock-alert-check.php` | задача пользователя `ada-russia` каждые 15 минут |

`hiblack-stock-alert-check.php` рассылает уведомления «товар снова в
наличии». Подписки создаёт `POST /api/stock-alert` и складывает их рядом
со скриптом, в `hiblack-stock-alerts/` — тоже выше публичной папки, чтобы
адреса подписчиков нельзя было скачать по прямой ссылке. Скрипт отправляет
одно письмо и сразу удаляет подписку; невостребованные записи истекают
через 180 дней.

Сухой прогон без писем:

```sh
php hiblack-stock-alert-check.php --dry-run
```

Он печатает `checked / ready / sent / expired / errors` и ничего не
отправляет. Данные подписчиков в репозиторий не попадают.
